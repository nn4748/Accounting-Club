# موقع نادي المحاسبة

الموقع الرسمي لنادي المحاسبة بجامعة الإمام محمد بن سعود الإسلامية — https://accclubimamu.com

موقع ثابت (HTML/CSS/JS) بدون أي أدوات بناء (build tools)، يُنشر مباشرة كما هو.

## هيكلة الملفات

```
.
├── index.html              الصفحة الرئيسية
├── events.html              صفحة الفعاليات (تعرض كل الفعاليات، قديمة وحالية)
├── register.html            صفحة التسجيل بالفعاليات
├── visits.html               صفحة الزيارات الميدانية
├── volunteer-hours.html     صفحة الساعات التطوعية
├── company-builder.html      محاكي "ابنِ شركتك" (قوائم مالية تفاعلية)
├── 404.html                  صفحة الخطأ 404
├── css/
│   └── styles.css            التنسيقات المشتركة (تستخدمها index.html و404.html فقط)
├── js/
│   ├── home.js                سكربت الصفحة الرئيسية (القائمة، الفعاليات، اللعبة، البوت)
│   └── company-builder.js     منطق محاكي "ابنِ شركتك"
└── assets/
    ├── events/                صور الفعاليات (فعاليات سابقة)
    ├── sponsors/               شعارات الجهات الراعية/الشريكة
    └── visits/                 صور الزيارات الميدانية
```

**ملاحظة مهمة**: الصفحات `events.html`، `register.html`، `visits.html`، `volunteer-hours.html` كل وحدة منهم **مستقلة بذاتها** — فيها `<style>` و`<script>` مكتوبين داخلها مباشرة، ما تعتمد على `css/styles.css` ولا `js/home.js`. تعديل أي شي بهالملفات لازم يصير داخل نفس الملف.

## من وين تجي بيانات الفعاليات؟

بيانات الفعالية "الحالية" (الاسم، التاريخ، الوصف، الصورة) ما هي مخزنة بالكود — تجي من **Google Apps Script Web App** مربوط بشيت جوجل خارجي (يديرها فريق النادي من الشيت مباشرة، بدون تعديل كود). كل من `js/home.js` و`events.html` يجيبون نفس البيانات من نفس الـ API.

## التسجيل بالفعاليات

- التسجيل العام يروح لشيت جوجل عام واحد.
- بعض الفعاليات (مثل "دقة المحاسبة" و"CIA & CISA") إلها **فورم جوجل وشيت ردود مستقلين**، مع حد أقصى لعدد المسجلين (`*_LIMIT`) يتحقق منه الكود بقراءة الشيت كـCSV. كل فعالية من هذا النوع لها قسم خاص بالكود بثلاث ملفات: `register.html`، `js/home.js`، `events.html` — أي تعديل على فعالية من هذا النوع لازم ينعكس بالثلاثة.
- مطابقة اسم الفعالية الخاصة تصير بـ regex (مو مطابقة حرفية)، عشان تشتغل حتى لو تغيّرت صياغة الاسم بالشيت شوي.

## اللعبة والبوت (معطّلين مؤقتاً)

كود لعبة "اختبر معلوماتك المحاسبية" ومساعد الذكاء الاصطناعي موجود بالكامل داخل `js/home.js`، بس العناصر اللي تفتحهم بالواجهة **معطّلة مؤقتاً** بتعليقها HTML داخل `index.html` (بحث عن `gameFab` أو `botFab`). لإعادة التفعيل: شيلي التعليق عن القسم المعني بـ`index.html` فقط — الكود جاهز وما يحتاج أي تعديل.

## سير العمل المعتاد

تعديل → اختبار (syntax + تجربة فعلية بالمتصفح) → commit → push → Pull Request → دمج (squash) → مزامنة الفرع مع main.
